## 1. AI Agents, Skills & Developer Tooling

* **[Meta Muse](https://ai.meta.com/muse/)**  
  Meta’s personal autonomous AI agent powered by the Muse Spark model family. Running inside an isolated Secure Virtual Machine, Muse executes multi-step background tasks across a shared browser and connected apps—such as managing calendars, researching purchases, monitoring goals, and building custom tools—with user-controlled permission guardrails.
* **[OpenAI Academy: ChatGPT Sites](https://openai.com/academy/chatgpt-sites/)**  
  An official OpenAI guide to creating, deploying, and hosting lightweight internal websites and web applications (such as launch trackers, team dashboards, onboarding portals, and interactive calculators) directly through natural-language prompts in ChatGPT and Codex, complete with built-in access controls and storage.
* **[Skills.sh — The Open Agent Skills Ecosystem](https://www.skills.sh/)**  
  An open registry and MIT-licensed CLI (`npx skills`) created by Vercel Labs for discovering, security-auditing (via Gen, Socket, and Snyk), and installing reusable `SKILL.md` procedural workflow packages across more than 30 AI coding agents, including Claude Code, OpenAI Codex, Cursor, and GitHub Copilot.
* **[AI Token Scrooge (Lance Larsen)](https://lancelarsen.com/posts/ai-token-scrooge)**  
  An open-source Windows desktop and system tray utility built with .NET 10 MAUI and the Windows App SDK that monitors usage allowances, refresh countdowns, and expiring earned resets across OpenAI Codex, GitHub Copilot, and Anthropic Claude without consuming API tokens.
* **[Zoo — AI-Native Hardware Design & CAD](https://zoo.dev/)**  
  An AI-native mechanical engineering and CAD platform built on a custom geometry kernel and the KCL code-CAD language. It combines Zoo Design Studio, programmatic CAD APIs, a Model Context Protocol (MCP) bridge for AI agents, automated Design for Manufacturing (DfM) and structural checks, and direct-to-metal CNC machining.

## 2. AI Search, SEO & Answer Engine Optimization (AEO)

* **[Google Search Central: Optimizing Your Website for Generative AI Features](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide)**  
  Google’s official technical documentation explaining how sites appear in AI Overviews and AI Mode via retrieval-augmented generation (RAG). It emphasizes foundational SEO, crawlability, and original "non-commodity" content while mythbusting popular third-party AEO/GEO tactics like content chunking, creating `llms.txt` files, or rewriting prose specifically for LLMs.
* **[Ad Age: Answer Engine Optimization (AEO) — What Marketers Need to Know](https://adage.com/technology/ai/aa-aeo-answer-engine-optimization-what-marketers-need-to-know/)**  
  An industry guide for marketers examining the shift from traditional search engine keyword rankings to Answer Engine Optimization (AEO)—focusing on how brands structure authoritative, citable content and measure share-of-voice across generative AI assistants and answer engines.

## 4. Architecture, Event Discovery & Media

* **[Double Envelope House (Wikipedia)](https://en.wikipedia.org/wiki/Double_envelope_house)**  
  An encyclopedia overview of Lee Porter Butler’s 1975 passive solar "house within a house" residential architecture concept, which uses a south-facing solarium and a continuous double-walled air cavity to circulate solar heat in winter and earth-cooled air in summer via natural gravity convection.
* **[FindThatEvent](https://findthatevent.com/)**  
  A web-based event discovery utility designed to help users search, filter, and track upcoming community, local, and special-interest events in one place.
* **[Wildwood (2026) — IMDb](https://www.imdb.com/title/tt2056785/)**  
  The IMDb page for Laika’s 2026 stop-motion animated dark fantasy film directed by Travis Knight, adapted from Colin Meloy and Carson Ellis’s novel *Wildwood* and featuring a voice cast including Peyton Elizabeth Lee, Jacob Tremblay, Carey Mulligan, and Mahershala Ali.
* **[One Piece — AniDB](https://anidb.net/anime/69)**  
  The comprehensive AniDB database entry for Toei Animation’s long-running anime adaptation of Eiichiro Oda’s *One Piece*, cataloging episode air dates, character relations, voice cast, staff credits, and release metadata since 1999.
